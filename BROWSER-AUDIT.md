# Сравнение BrO2 с браузерами Windows

Срез от 17 ноября 2026 года. Стабильные ветки Google Chrome [157](https://chromereleases.googleblog.com/2026/11/stable-channel-update-for-desktop_01744469280.html), Mozilla Firefox [160](https://developer.mozilla.org/en-US/docs/Mozilla/Firefox/Releases/160) и Opera [140](https://blogs.opera.com/desktop/) сверены по страницам релизов. Для Яндекс Браузера использована [справка настольного приложения](https://browser.yandex.ru/help/ru/about/install). Номер установленной стабильной версии Яндекс Браузера не подтверждён. В Windows найден Chrome 157.0.8103.79. Сравнение возможностей основано на документации. Живые проверки BrO2 записаны в конце файла.

Ссылки в столбцах конкурентов ведут к справке по соответствующему разделу. Знак «?» означает, что поддержку в выбранной конфигурации пока не подтвердили. Для строк с широкими ссылками по разделам точные условия нужно сверять перед реализацией. P1 — повседневные сценарии, P2 — расширение повседневной функциональности, P3 — дополнительная оценка. Синхронизация требует учётной записи соответствующего браузера. Возможности с постепенным включением и региональными ограничениями нельзя считать доступными во всех установках.
