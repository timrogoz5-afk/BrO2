# BrO2

Браузер для Windows на Electron. Интерфейс и страницы сайтов работают в отдельных представлениях.

## Запуск

Если в папке проекта есть сборка `BrO2-portable`, откройте `BrO2.exe` двойным щелчком. Для этой сборки не нужны Node.js или npm. При переносе приложения копируйте папку `BrO2-portable` целиком.

Для запуска из исходников понадобятся Node.js с npm и доступ к интернету. Выполните в PowerShell из папки проекта:

```powershell
npm install
npm start
```

## Пароли и переезд из Chrome

1. Войди на сайт через форму HTTPS. После подтверждаемого входа BrO2 предложит сохранить или обновить пароль. В панели видны сайт и логин. Действие «Никогда для этого сайта» добавляет сайт в исключения.
2. При следующем посещении BrO2 предложит сохранённые логины, как только появится подходящая форма входа. Выбери логин мышью или нажми `Alt+↓`, выбери строку стрелками и нажми `Enter`. Кнопка с ключом рядом с адресом тоже открывает список. `Esc` закрывает панель и возвращает фокус. BrO2 заполняет поля и оставляет отправку формы тебе.
3. Открой **Настройки → Пароли**, чтобы добавить запись вручную, изменить её, скопировать пароль, удалить запись или управлять исключениями. Здесь же можно отключить предложения сохранения.
4. Открой **Настройки → Импорт из Chrome** и выбери CSV с паролями или HTML с закладками. Посмотри предварительный результат и подтверди импорт. Для замены конфликтующих паролей отметь соответствующий пункт. Закладки доступны там же и экспортируются в HTML. Ярлыки новой вкладки хранятся отдельно.

Хранилище паролей защищает секреты через `safeStorage` Electron под учётной записью Windows. При переносе на другой компьютер заново импортируй пароли через CSV. Для импорта аккаунт BrO2 не нужен.

### Поддерживаемые формы

- Обычные формы в главном документе HTTPS, которые отправляют `POST` на тот же адрес происхождения. Схема, хост и порт должны совпадать. Поддерживаются динамически вставленные формы, ввод логина и пароля в два шага, а также поля с `autocomplete="new-password"` для генерации.
- Предложение сохранения появляется после успешного `POST` на том же HTTPS-сайте, когда форма входа исчезла и страница не показывает ошибку или поле одноразового кода. Поддерживаются обычная отправка формы и запрос из JavaScript в текущей странице. Запись можно добавить вручную, если результат входа не удалось распознать.
- Поля уже введённого логина и пароля защищены от перезаписи при заполнении. Заполнение доступно только для подходящего видимого поля на текущей странице. HTTP, вложенные фреймы, чужой хост или порт, чужой адрес отправки формы и ошибки сертификата исключаются.

## Основные действия

- Вкладки, навигация назад и вперёд, обновление и остановка загрузки.
- Адресная строка принимает URL и отправляет запросы в выбранную поисковую систему. По умолчанию используется Google.
- Сайты работают в отдельном профиле и сохраняют cookies между запусками. Запросы сайтов на разрешения отклоняются.
- `Ctrl+T` открывает вкладку, `Ctrl+W` закрывает её, `Ctrl+Tab` переключает вкладки, `Ctrl+L` выделяет адрес, `F5` обновляет страницу.
- Кнопки окна находятся справа от вкладок. За свободное место в этой строке можно перетаскивать окно.
- Адресная строка предлагает совпадения из локальной истории. Стрелки выбирают подсказку, `Enter` открывает её, `Esc` закрывает список.
- Звезда справа от адреса добавляет или удаляет сайт из ярлыков новой вкладки. Кнопка «Добавить ярлык» позволяет ввести сайт вручную.
- Шестерёнка или `Ctrl+,` открывает настройки. Тема, цвет акцента, поисковик и один из четырёх режимов анимации сохраняются между запусками. Уменьшение движения в Windows имеет приоритет. Там же можно очистить историю подсказок.

## Расширения

На странице расширения в Chrome Web Store нажми **Установить в BrO2** в панели браузера. На открывшейся вкладке выбери **Проверить пакет**, проверь разрешения и нажми **Добавить**. Ссылку из магазина также можно вставить через **Меню → Расширения**. BrO2 скачивает пакет с серверов Google, проверяет подписи Chrome Web Store и разработчика и сохраняет расширение в профиле.

На вкладке «Расширения» также можно выбрать **Добавить из папки** и указать распакованную папку с `manifest.json`. BrO2 загружает включённые расширения при запуске. Для обновления удали расширение из списка и добавь новую версию.

В том же списке можно отключить, включить и удалить расширение. Панель и настройки расширения открываются в отдельных вкладках, если расширение их объявляет. Из такой панели запрос активной вкладки может вернуть саму панель. Чтобы убрать изменения, которые скрипт уже внёс на сайт, обнови страницу.

Electron 45.3.3 поддерживает часть Chrome API. Checker Plus for Gmail 36.7.1 устанавливается и открывает панель. Для уведомлений, push-синхронизации и входа через API расширений ему нужны `chrome.notifications`, `chrome.gcm` и `chrome.identity`, которых нет в этом движке. Фоновый процесс Lunar Reader 2026.10.13 останавливается при обращении к `chrome.commands.onCommand`, поэтому оформление страницы не меняется. [Поддержка расширений в Electron 45.3.3](https://raw.githubusercontent.com/electron/electron/v45.3.3/docs/api/extensions.md)

## Горячие клавиши Windows

| Действие | Клавиши |
| --- | --- |
| Новая, закрыть, восстановить вкладку | `Ctrl+T`, `Ctrl+W` или `Ctrl+F4`, `Ctrl+Shift+T` |
| Следующая и предыдущая вкладки | `Ctrl+Tab` / `Ctrl+Shift+Tab` или `Ctrl+Page Down` / `Ctrl+Page Up` |
| Вкладка по номеру и последняя | `Ctrl+1…8`, `Ctrl+9` |
| Новое окно, инкогнито, закрыть окно | `Ctrl+N`, `Ctrl+Shift+N`, `Alt+F4` |
| Выделить адрес | `Ctrl+L`, `Alt+D`, `F6` |
| Назад и вперёд | `Alt+←` / `Alt+→` или `Backspace` / `Shift+Backspace` вне полей ввода |
| Обновить, обновить без кеша, остановить | `F5` или `Ctrl+R`, `Ctrl+F5` или `Ctrl+Shift+R`, `Esc` |
| Домашняя страница, полноэкранный режим | `Alt+Home`, `F11` |
| Масштаб страницы | `Ctrl++`, `Ctrl+-`, `Ctrl+0` |
| Прокрутка вниз, вверх, в начало и конец | `Пробел` или `Page Down`, `Shift+Пробел` или `Page Up`, `Home`, `End` |
| Поиск на странице, история, загрузки | `Ctrl+F`, `Ctrl+H`, `Ctrl+J` |
| Добавить закладку, переключить панель | `Ctrl+D`, `Ctrl+Shift+B` |
| Печать, сохранение веб-архива MHTML | `Ctrl+P`, `Ctrl+S` |
| Исходный код, инструменты разработчика, диспетчер задач | `Ctrl+U`, `F12` или `Ctrl+Shift+I`, `Shift+Esc` |

Окно инкогнито использует временный сеанс. Расширения, пароли, закладки и история обычного профиля в нём недоступны. Скачанный файл остаётся на диске.

## Вход в профиль BrO2 через Google

1. В [Google Cloud](https://console.cloud.google.com/auth/clients) настрой экран согласия и создай клиент OAuth типа **Приложение для компьютера**. Скачай JSON клиента. Если проект использует список тестовых пользователей, добавь в него аккаунт для входа.
2. В BrO2 открой **Настройки → Профиль BrO2 → Подключить OAuth-клиент** и выбери JSON.
3. Нажми **Войти через Google**, подтверди вход в системном браузере и вернись в BrO2.

BrO2 сохраняет имя и подтверждённый email профиля. Cookies сайтов и профиль BrO2 хранятся отдельно. Настройки и вкладки между устройствами сейчас не синхронизируются.

## Проверки и упаковка

Из корня проекта выполни `node scripts/check.js` для проверки синтаксиса и `npm test` для тестов хранилища, импорта, расширений и клавиатурных команд. Команда `node scripts/package-portable.js` обновляет portable-копию и сверяет файлы с исходниками. Для прогона portable-сборки выполни `node tests/portable-passwords.js` в Windows с Node.js 24 и PowerShell 7. Чтобы также проверить расширение, окна и команды, перед запуском задай в PowerShell `$env:BRO2_TEST_FEATURES = '1'`. Прогон создаёт временный профиль и локальные HTTPS-страницы с тестовыми данными.
